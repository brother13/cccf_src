================================================================================
                              执行法官助手系统
                              项目功能说明书
================================================================================

一、项目概述
--------------------------------------------------------------------------------
1.1 项目名称
    执行法官助手

1.2 技术架构
    前端：Vue 2.6 + Element UI 2.13 + Vue Router 3.0 + Vuex 3.1
    后端：ThinkPHP 5.0 (PHP)
    数据库：MySQL
    运行环境：MAMP/LAMP

1.3 目标用户
    法院执行局工作人员、法官、书记员

================================================================================

二、系统登录与权限管理
--------------------------------------------------------------------------------
2.1 用户登录
    - 支持用户名密码登录
    - Token 身份验证机制
    - 自动登录状态保持（7天有效期）
    - 超时自动退出（600秒无操作）

2.2 权限控制
    - 基于角色的访问控制（RBAC）
    - 支持多角色配置
    - 页面级权限控制
    - 按钮级权限控制

2.3 主要角色
    - XZTZ：执行款台账权限
    - CCCF：财产查封权限
    - XDFKTX：续冻提醒权限
    - PZ：凭证管理权限
    - THQD_QUERY_ALL：退回清单查询全部权限
    - DKP_QUERY_ALL：待开收据查询全部权限

================================================================================

三、功能模块说明
--------------------------------------------------------------------------------

3.1 首页工作台
--------------------------------------------------------------------------------
    功能描述：系统登录后的主界面，集中展示各项提醒事项

    3.1.1 执行查控提醒
        - 财产查封1周内到期提醒
        - 财产查封1月内到期提醒
        - 续冻金额提醒

    3.1.2 执行款台账提醒
        - 新到账10天未发还提醒
        - 延缓5天内到期提醒
        - 退回清单数量提醒
        - 待开收据数量提醒

    功能特点：
    - 数字角标实时显示待处理数量
    - 点击直接跳转到对应功能页面
    - 基于权限动态显示可访问功能

--------------------------------------------------------------------------------

3.2 执行款台账模块
--------------------------------------------------------------------------------
    功能描述：管理执行款项的收付、退款、台账统计

    3.2.1 执行款台账
        - 台账列表展示
        - 多条件组合查询（案号、时间、金额、承办人等）
        - 台账数据导出（Excel）
        - 案款状态标记
        - 超期提醒标识
        - 备注功能

    3.2.2 收款明细表
        - 收款记录列表
        - 收款数据统计
        - 数据导出

    3.2.3 退款明细表
        - 退款记录列表
        - 退款状态跟踪
        - 数据导出

    3.2.4 退回清单（新增）
        - 退回款项记录管理
        - 字段：案号、退回金额、经办人、出账日期、出账状态、
               收款人、收款人账号、收款人开户行
        - 多条件查询（案号、经办人、收款人、日期范围、状态）
        - 数据导出Excel
        - 权限控制：默认仅显示当前用户数据
        - 高级权限：可查看全部人员数据

    3.2.5 待开收据（新增）
        - 待开收据记录管理
        - 字段：案号、当事人、到账金额、到账日期、摘要、承办人
        - 多条件查询（案号、承办人、当事人、日期范围）
        - 数据导出Excel
        - 权限控制：默认仅显示当前用户数据
        - 高级权限：可查看全部人员数据

--------------------------------------------------------------------------------

3.3 财产查封模块
--------------------------------------------------------------------------------
    功能描述：管理财产查封、续冻等执行措施

    3.3.1 查封清单管理
        - 查封财产登记
        - 查封到期提醒
        - 续冻操作
        - 解封操作

    3.3.2 续冻提醒
        - 到期前提醒列表
        - 自动计算到期时间
        - 短信/系统消息通知

    3.3.3 查控到期统计
        - 1周内到期统计
        - 1月内到期统计
        - 分类统计报表

--------------------------------------------------------------------------------

3.4 档案管理模块
--------------------------------------------------------------------------------
    功能描述：执行案件档案的电子化管理

    3.4.1 档案列表
        - 档案信息录入
        - 档案查询检索
        - 档案状态管理

    3.4.2 档案分类
        - 按案件类型分类
        - 按承办部门分类
        - 按案件状态分类

--------------------------------------------------------------------------------

3.5 基础数据管理
--------------------------------------------------------------------------------
    功能描述：系统基础数据的维护管理

    3.5.1 部门管理
        - 部门信息维护
        - 部门人员配置

    3.5.2 用户管理
        - 用户账号管理
        - 角色权限分配
        - 密码重置

    3.5.3 案件类型管理
        - 案件类型配置
        - 执行标的分类

    3.5.4 数据字典
        - 系统参数配置
        - 下拉选项维护

--------------------------------------------------------------------------------

3.6 系统设置模块
--------------------------------------------------------------------------------
    功能描述：系统配置和个性化设置

    3.6.1 个人设置
        - 个人信息修改
        - 密码修改
        - 消息通知设置

    3.6.2 系统配置
        - 提醒时间配置
        - 导出配置
        - 界面主题设置

--------------------------------------------------------------------------------

3.7 报表统计模块
--------------------------------------------------------------------------------
    功能描述：各类执行数据的统计分析

    3.7.1 执行款统计
        - 收付款统计
        - 余额统计
        - 分类汇总

    3.7.2 案件统计
        - 案件数量统计
        - 结案率统计
        - 执行到位率统计

    3.7.3 承办人统计
        - 个人办案统计
        - 部门办案统计

    - 精确匹配查询

五、数据导出功能
--------------------------------------------------------------------------------

5.1 导出格式

    - 自动列宽调整

5.2 导出内容
    - 当前页数据导出

六、系统接口说明
--------------------------------------------------------------------------------

6.1 接口规范
    - 统一POST请求
    - RESTful接口设计
    - JSON数据格式
    - Token身份验证

6.2 主要接口模块
    - /user/* 用户相关接口
    - /data/* 数据操作接口
    - /cccf/* 档案管理接口
    - /thqd/* 退回清单接口
    - /dkp/* 待开收据接口
    - /dept/* 部门管理接口
    - /group/* 用户组接口
    - /node/* 流程节点接口
    - /sjcl/* 事件处理接口
    - /sys/* 系统配置接口
